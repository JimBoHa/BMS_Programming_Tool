# Contextual encoding-preserving terminal copies

`UI-NATIVE-TERMINAL-LABELS-001` uses the explicit encoding-preserving profile in
the existing Points & I/O local terminal reassignment task. Original archive and
captured saved-effective copies retain their separate source/basis choices. No
new navigation, tile, electrical-mode control or field Apply action is added.

The existing selected route, graph/CAF entry, bounded per-workspace draft,
navigation retention, input-operation exclusion and lifecycle/target invalidation
remain. Source responses require the new envelope/compiler versions, actual
input/occupancy evidence and strict recorded ASCII/UCS-2 encoding metadata.
Only a reviewed free universal terminal on the same controller is offered.

Review checks the exact previous/destination input, object/reference, original and
saved-effective source/record/property hashes, payload offsets/widths and recorded
charset. An ASCII conversion of a UCS-2 label is refused. The complete original
JSON document and each nested compiler seal are verified using preserved numeric
tokens and Python-compatible key/string ordering. Parsed display data must match
that document. This retains floating-point spelling, signed zero, large integers
and Unicode keys, rather than resealing a JSON.parse/stringify round trip.

Save terminal review downloads the original response bytes. Save native terminal
copy still checks the artifact and all five export hashes. Both are local file
actions. Late HTTP or digest completion cannot restore a retired review or start
a download after the source, target, task or page lifecycle changes. Unsupported
sources retain their original evidence and cannot provide a reviewed export.

The old parser defaults and legacy API/compiler profiles remain independently
available. Existing field document checks retain their complete implementation;
the shared module only adds a separate local-document seal function. All backend
code, field transfer/recovery helpers, ledgers, engineering graphics and styles
remain unchanged in this delivery.

## Verification and remaining scope

Authored HTTP fixtures cover analog/binary UCS-2 original/effective copies,
exact native/review downloads, graph/offline and selected-controller entry paths,
navigation drafts, source/target/basis/lifecycle invalidation and malformed
evidence. Independent contract cases cover unsupported charsets, encoding
conversion, nested/outer seals, document/display binding, exact numeric tokens,
duplicate/truncated documents and delayed cryptographic digest completion.
Older terminal-copy and analog-field contract cases remain in qualification.

These checks use local protocol peers and isolated application state. They do
not establish live controller acceptance, physical terminal/wiring suitability,
binary field compilation, SA/IOM/cross-host reassignment or CCT/BTCVT acceptance.
Source-specific capability reporting for this explicit profile remains a
separate delivery. See [the backend profile](native-terminal-label-encoding.md).
