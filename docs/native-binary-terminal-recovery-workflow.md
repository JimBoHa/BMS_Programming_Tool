# Previous-terminal recovery in the configured binary input task

`UI-NATIVE-BINARY-TERMINAL-RECOVERY-001` places local preparation, explicit staging
and a fresh confirmed field review inside the existing configured binary input task
in Points & I/O. It uses the open controller/application context and retained source.
No new global destination or stylesheet is required.

The operator supplies a previous verified binary terminal transfer receipt, prepares
the local previous-terminal proposal, inspects its evidence and explicitly stages
it. Preparation and staging do not query or modify a controller. An independent
closed browser contract checks the report and origin seals, current source,
controller/ref/terminal pair, typed binary configuration, counter presence and
recorded terminal-label encoding. Missing or altered evidence cannot become a
staged draft or field authority.

The ordinary binary selection and destination remain available. Task navigation
retains bounded local drafts; switching source or target retires field review.
Manual edits clear recovery lineage. Discard clears the recovery proposal, saved
ordinary selection and parent receipt. Evidence can be saved locally without
starting a transfer. A verified recovery restores the ordinary draft and marks the
old capture stale for related input writers.

Field work follows Review → Apply → Readback with all three existing confirmations.
The distinct binary recovery origin remains attached to review and child receipt;
missing or substituted lineage cannot become an ordinary binary move. Current saved
counters may change while configuration and optional-field presence remain bound.
Late asynchronous replies cannot repopulate a retired review or receipt. An uncertain
outcome keeps original evidence and uses readback without replay.

Graph and CAF entry paths retain their existing application/controller context.
Recorded source values, fresh field verification and local proposals remain distinct.
The interface follows the existing teal styling and progressive disclosure.
