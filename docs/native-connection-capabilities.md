# Actual native connection capability discovery

In **Program → Native backup defaults**, select a retained backup, inspect it,
and open **Operation support for this native backup**. The existing table now
includes **Save a matching native connection archive copy** and **Compile a
matching saved-effective native connection**. It derives support from the actual
retained graphs and saved values. Controller names and model inventories do not
supply a replacement application or point list.

This is `CAP-NATIVE-CONNECTION-001`, capability profile
`native-backup-operation-capabilities/12`. Its 24 ordered rows retain the earlier
22 operations and their qualification rules. Original archive connection support
is independent of saved-schema and historical identity errors. Effective support
requires the separate identity-qualified saved merge and unchanged original graph
and continuation structure. A saved configuration can admit a matching endpoint
that the original archive configuration does not. Conversely, readable records
do not imply either connection operation is supported.

## Actual witness, separate from edit authority

For each supported connection operation, qualification records an actual diagram,
prototype index/tuple, observed matching source and unused matching destination,
member indices, bounded candidate/connection/block counts, continuation shape and
exact source/record/property digests. Effective witness hashes identify the merged
captured application; archive witnesses identify original File 3. The result keeps
source-specific errors and never promotes a witness to a field preflight or Apply.

Candidate search uses the installed profiles' actual class/configuration
signatures, observed pins, input ownership, execution order and directed paths.
It uses integer member sets and bounded graph reachability rather than reparsing
the same graph for every candidate. The current 512-member, connection/tag,
reference and file bounds remain. A proposed witness is independently rechecked
with the original compiler inspector before support is reported. Final review
still checks all source/prototype guards, output size, framing and exact native
readback. Eligibility alone is not a compiled artifact or a controller-resource
compatibility guarantee.

Existing wire-source capability discovery uses the same bounded reachability
index while retaining its earlier-execution, observed pin, exact source
configuration, cycle and original-index-width predicates. Removing the selected
incoming edge to a destination cannot change paths starting at that destination:
any path using that edge merely returns to its start, so that cycle can be
removed. The original inspector rechecks the selected wire and supplies the exact
candidate count. Byte compilers, field transfer, ownership, intent and recovery
rules remain unchanged.

## API and interface

The token-admitted endpoint remains
`POST /api/bacnet/controller/native-application/inspection/capabilities`.
Capture ID and manifest hash remain required. The optional `capability_profile`
selects current profile 12 or explicit legacy profile 11; omitted selection now
returns 12. Unknown versions, extra authority/address fields and wrong types are
refused. Explicit legacy 11 returns its original 22-row shape and qualification,
without new connection fields. Both versions verify all original Files 3/11/12
and grant no current identity, controller query, field action or Apply authority.

The browser requests profile 12 and checks its complete ordered operation set,
original provenance, file sizes/hashes, identity/merge bindings, bounded witness
shape and matching row status. Altered metadata cannot populate a table or an
export. Source changes retire delayed results, including A→B→A selection. Local
program drafts retain their existing owners. **Save exact operation analysis**
downloads the original admitted response bytes for the current source.

Verification compares search results with exhaustive calls to the existing native
inspectors across independently authored configurations, observed ports, input
ownership, order, width and cyclic graphs. A 512-member strongly connected graph
has free inputs but correctly supplies no witness, with at most one initial
connection inspection and no per-edge legacy inspection. Tests count inspections,
not elapsed time. Metadata, duplicate input, tag and reference bounds remain;
no quota, timeout or retry increase hides an unsupported source.

Current and explicit legacy reports are compared as complete projections across
matching, unknown saved, unverified, full-input and no-continuation sources.
Strict local HTTP, corruption/source guards, source/installed browser tables,
exact JSON exports, altered results, drafts and source transitions retain their
separate checks. Tests use authored files and loopback peers, with no site, VM or
Bluetooth operation.

This adds source-specific discovery for the separately qualified
[archive addition](native-matching-connection-copies.md) and
[saved-effective addition](native-effective-connection-compiler.md). It does not
add a compiler, field transfer, arbitrary blocks or hardware allocation, package
qualification or physical/CCT/BTCVT acceptance. JCI-01 remains partial overall.
