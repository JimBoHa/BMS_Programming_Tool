# Captured typed analog terminal transfer support

`FMT-NATIVE-ENCODED-ANALOG-CAPABILITIES-001` adds explicit capability profile 18.
It appends a typed analog terminal-transfer witness to the complete profile-17
report. Earlier profiles and the default report keep their existing behavior.
Analysis compiles one actual existing analog input to the first recorded free
universal terminal in memory. It retains no edit, plan, receipt or transfer token.

The witness includes exact source/effective/native hashes, the actual saved-setting
merge, object/reference/terminal/configuration guard, closed typed configuration
and field-presence evidence, observed ASCII/UCS-2 label encoding and output/compiler
hashes. Paired absent output endpoints remain absent. Missing or unknown saved
settings, unsupported configuration types/presence, conflicting saved binding,
unknown charset, unsupported hosts and unavailable destinations prevent a witness.
Outputs keep their separate namespace. Recorded availability never verifies wiring.

Support distinguishes unsupported source, recorded source mismatch, unavailable
captured transport and fresh field preflight still required. A successful witness
is a local compilation result, not current identity verification, physical
acceptance or permission to apply. Every actual transfer still requires the
independent configured-analog workflow, current capture/settings, all confirmations,
one-use review and complete native plus published readback.

The existing contextual terminal-support table adds the configured analog row.
Its independent browser contract admits the complete predecessor report and the
closed new witness, checking typed values, absent endpoints, storage consistency,
source/static/dynamic merge bindings, destination availability and status. Original
analysis downloads remain exact. Source/task ownership, graph/CAF context, contained
engineering-table scrolling and the existing main operations table remain intact.
No address entry, global destination or graphics stylesheet is added.

Verification covers ASCII/UCS-2, native/compressed containers, present/absent linear
endpoints, saved conflicts, unsupported datatypes/hosts, output namespace, source
identity and transport. Disconnected API checks forbid field/mutation paths.
Browser tests cover source-specific support, exact exports, malformed witnesses,
legacy evidence, task/source retirement, graph/CAF and phone/desktop layouts.
Retained private VMA sources also produce actual witnesses without changing files;
unsupported PCG evidence remains unsupported. No private inventory is embedded.

Recorded Changes/History metadata and previous-terminal recovery for profile 4
remain separate work. This delivery does not extend compilation, field writers,
allocation/electrical edits, SA/cross-host moves, packages/resources or physical/
CCT/BTCVT acceptance. IO-02/JCI-09 remain partial.
