# Native execution-order support from an actual backup

In **Program → Native backup defaults**, select a retained backup, inspect it and
open **Native backup operation support**. Select **Include native execution-order
support** to analyze the actual retained File 3/11/12 source. The two new rows
separate local order compilation from controller-transfer prerequisites. Other
analysis choices retain their previous settings when returning to them.

This implements `COMM-NATIVE-ORDER-CAPS-001` with explicit capability profile
`native-backup-operation-capabilities/22`. Profiles 11–21 and the API default
profile 12 retain their existing behavior. The new profile preserves the complete
profile 14 prefix and adds independently checked order evidence.

## Actual compilation evidence

The analyzer requires recorded vendor 5 identity and the existing qualified
saved-value merge. It examines recorded native activity/sequence diagrams,
members, execution-order tags and wire relationships. It seeks a nontrivial
adjacent member swap that preserves every original before/same/after relationship
and fits the original destination widths. It then runs the actual local compiler
and independent readback. A separate transfer compilation checks the selected
configuration guard and application-field qualification against the same output.

The evidence contains the actual record, source-bound request, complete local
review and separate transfer compilation where supported. It creates no user
draft, controller review token, transfer intent, receipt or field command.
Recorded configuration and values remain historical. A local review digest is
not a field-transfer authorization.

The probe examines at most eight diagrams and makes at most eight compilation
attempts. Its retained witness is bounded to 96 KiB. These are analysis limits,
not controller capacities or general compiler limits. A failed bounded search,
single-member/fully ordered diagram or oversized witness reports **not evaluated**;
it does not establish that no other permutation can compile. Inspect the actual
diagram and choose an intended order separately when this probe finds no witness.

## Interpreting the rows

| Result | Meaning |
| --- | --- |
| Local **source qualified** | An actual nontrivial permutation passed local saved-effective compilation and readback. |
| Transfer **preflight required** | That same witness passed the transfer compiler and captured plain IPv4 prerequisites. Current access remains unchecked. |
| Transfer **transport unavailable** | Local compilation remains useful; the captured interface lacks this transfer profile's plain IPv4 prerequisites. |
| Transfer **unsupported source** with local qualification | Local compilation passed, but separate transfer-field qualification failed. Its error remains explicit. |
| **Source mismatch** | Recorded identity does not qualify the source. |
| **Unsupported source** / **not evaluated** | Unsupported saved encoding or bounded analysis prevented a witness; read the accompanying reason. |

The browser independently checks the source envelope, read-only authority flags,
legacy prefix, exact operation IDs, limits/counters, full local source/review,
original phases/widths and separate transfer compiler/guard seals. Altered
evidence is not displayed as a support table or exported as interpreted evidence.
Mode/source/task changes retire stale analyses and cached export handlers. Exact
analysis downloads preserve original response bytes.

Use the separate [order transfer workflow](native-order-transfer.md) for a fresh
controller review, explicit confirmations, one durable restore and complete
readback. This analysis queries no controller or adapter. It establishes no
current identity, release/package/resource/runtime, CCT or physical/BTCVT
acceptance. Qualification uses authored local sources and isolated application
servers; private controllers and VM software are not exercised.
