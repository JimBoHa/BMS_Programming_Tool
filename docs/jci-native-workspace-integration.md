# Integrated native engineering workspace

This change combines the existing captured-source operation matrix, actual
MOI/MOZ reading and native record explorer with the newer Real-default file-copy,
saved-setting compiler and one-default controller transfer workflows. It retains
each operation's original scope and the controller/application layout.

In **Program → Controller application**, a published File can supply diagrams,
records, stored properties and operation evidence. The record explorer and
capability table inspect the same immutable capture as the local file-copy editor.
Opening either view does not discard an unfinished field draft or send a native
backup/restore command. A `.moz` label is accepted only when the actual bytes match
the supported MOI container/decoder; it is not a new proprietary archive decoder.

The operation table now distinguishes a local Real-default copy, an effective
default compiler requiring a separate identity-verified native File 3/11/12
snapshot, and the separately reviewed field transfer. A generic published File
never invents saved parameter values. Current interface restrictions apply to
field transfer; they do not prevent offline compilation of an existing native
backup. No source-analysis row prepares or authorizes a controller write.

**Program → Native backup defaults** retains its independent native capture,
fresh-setting checks, compile/export, one-use transfer, preservation readback and
uncertainty recovery. Identity commissioning retains its own reviews and receipts.
General logic authoring, native package/resource validation, hardware allocation,
other transport families and physical acceptance remain separate.

Merge resolution preserves existing requirement/capability rows by identifier and
combines the two JCI-02 backlog credits. Test peers retain all prior source variants
and startup/backend pinning; `.moi` and `.moz` diagram checks both keep operation
assertions. The combined browser workflow inspects capabilities and native records
while retaining an invalid local Real-default draft. No older layout or fixed model
inventory replaces the current workspace.
