# Source-specific native connection removal support

`FMT-NATIVE-CONNECTION-REMOVAL-CAPABILITIES-001` adds local archive and
saved-effective connection-removal rows to the existing Program native backup
operation table. Opening the source analysis does not connect to a controller,
compile a connection edit, enter backup mode, create an intent or prepare Apply.

The browser explicitly requests `native-backup-operation-capabilities/14` and
shows its 27 operations. The API's default remains profile 12. Explicit profiles
11, 12 and 13 retain their complete previous reports, including order, evidence,
wording and operation counts of 22, 24 and 25. Profile 14 wraps the unchanged
profile-13 implementation and adds two rows and their source evidence.

For each basis, the analyzer inspects actual native diagrams until it finds an
existing connection accepted by the qualified removal inspector. The witness
contains its diagram, exact native tuple, source/destination references,
connection index/count, member count, continuation kind and source/record/property
hashes. Optional Boolean/String continuation must align with the wire list.
Duplicate drivers or unsupported framing remain unavailable with bounded error
evidence. No candidate or pin is invented from the controller model.

Saved-effective support additionally requires the existing identity-qualified
File 3/11/12 merge and unchanged graph/continuation structure. Unknown saved
directories or mismatched captured identity can leave original-archive removal
available while withholding effective support. Retained settings are captured
configuration, not current measurements. A graph with no matching spare input
for a new connection can still contain an existing connection that is removable.
Local removal analysis is independent of the captured field transport.

Both witnesses explicitly withhold native fallback/retention verification and
field-transfer authority. The destination becomes unwired if the operator later
reviews and saves its separate local copy. A source-qualified analysis does not
authorize that edit: the removal review still rechecks the exact selected source,
record, property, continuation, count and tuple, then verifies output bytes.

The existing table preserves source ownership, exact JSON downloads, explicit
reanalysis, compact/phone layout and late-response retirement. Client admission
checks both new witnesses, saved-source bindings and row statuses, together with
the complete previous matching-connection evidence. Malformed or contradictory
results withhold the table/export. The shared engineering canvas, styling and
global navigation remain unchanged.

Authored native applications and isolated browser/API state qualify the software
scope. General native authoring, hardware reassignment, controller resources,
packages/runtime semantics, removal transfer/recovery and CCT/physical/BTCVT
acceptance remain separate. JCI-01/JCI-03/JCI-09 remain partial overall. See the
[local removal compiler](native-connection-removal-copies.md) and
[Program workflow](native-connection-removal-workflow.md).
