# Recorded Float Comparison CAF creation

`FMT-CAF-COMPARISON-COPY-001` copies one actual version 1.0 Float Comparison
primitive and its four port objects into a separate local CAF. The class/type-560
parent has properties 75/32527/518/3184/3670. This profile preserves the recorded
Setup enum-set-287/StandardName enum-set-432 pairs 1/28, 2/31 or 3/32. It assigns
no undocumented operator meanings to those numbers.

The required child order is the recorded class-531/type-5 output at port 85,
followed by class-526/type-2 inputs 50083, 50084 and 637. Children retain their
identity/Item Reference/Attribute ID schema; a recorded Float input may also
retain native metadata-661 and its stored Float default. Missing defaults stay
missing. Port 637 exists as a child even when the parent's 3184 array does not
expose it. The writer preserves actual exposure and order. Enum-input comparisons
and other schemas remain refused.

## Local preservation and review

Five consecutive local identities derive from all actual object IDs and typed
BACoid references. Existing allocator bounds remain, with an additional check
for all five slots. Each child retains its type and exact hierarchy. One graph
member, one execution entry after the source prototype and one layout record are
added. Suggested position offsets retain the finite Float32 coordinate contract;
the operator's selected spelling is preserved.

All original objects, incoming/outgoing connections, continuation records and
unrelated graph properties remain exact. Source wires stay with the original
prototype; the new comparison is unconnected. Parent setup, standard name,
exposed-port order, child defaults/metadata and every nonidentity copied byte
are preserved. Original ZIP entry attributes/comments, including zero attributes,
remain. Changed raw ZIP compression/container bytes are not claimed identical.
Independent parsing verifies the five new objects, expected graph, child
order/configuration and unchanged records before export.

Strict token-protected routes are
`/api/caf/{id}/comparison-copy/source`, `/preview` and `/export`. Source binds the
original diagram/prototype/four child hashes, exact setup/schema/ports, five-ID
mapping, membership/order/layout and position. Selection/creation/review seals
and artifact/review/source/creation headers qualify the clicked local output.
The client checks every child mapping, exposure and recorded default, all four
new child artifact hashes and actual exported bytes. Requests cannot supply a
guessed setup, mapping or operator/field authority. There is no Apply route,
field plan or controller query/write in this operation.

## Existing Program workspace

Open a CAF, select **Program → CAF file → Logic** and inspect **Copy a recorded
Float Comparison**. When an actual comparison is present with other supported
families, **Recorded block type** selects the focused task. Constant-only diagrams
retain their existing **Constant type** labels and controls. One creation task
and primary action stay visible, without a new destination or tile.

**Recorded comparison inputs** distinguishes copied defaults, omitted values and
actual port exposure. Enter the new block's position, review and save a separate
CAF. The reviewed result identifies five objects. Exact original review JSON is
separately downloadable. Open the copied CAF to connect the new member through
the existing guarded connection workflow.

Unfinished constant/comparison coordinates share the unchanged 32-context cache
without eviction. Passive inspection/type selection consumes no slot. Source,
prototype, kind, controller, task, lifecycle and visibility changes retire reviews
and late downloads while retaining local text. Ordinary CAF Save, viewport
dragging and existing wiring retain their contracts. Controller entry keeps the
selected route and the file/controller match unverified.
