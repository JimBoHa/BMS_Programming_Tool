# Local native terminal reassignment in Points & I/O

`UI-NATIVE-LOCAL-TERMINAL-COPY-001` exposes the separately qualified
[native terminal copy profile](native-terminal-copies.md) inside the existing
Points & I/O input configuration task. Open **Reassign an existing local terminal**,
select a retained capture and its original or saved-effective basis, choose an
existing movable input and a configured free local universal terminal, then
**Review local terminal copy** and **Save native terminal copy**.

The selected controller and retained source remain distinct and visible, including
Device, endpoint, router, network, station and capture time. Local copies work
offline and can use a retained source different from the selected controller.
This operation does not open a field interface or acquire transfer authority.

## Evidence and ownership

The source list is checked against immutable archive inspection before the
terminal-specific source is opened. Client admission verifies exact capture,
snapshot, source, files, route, basis, input identity, terminal occupancy, fixed
DPT, record and property evidence. An effective source additionally retains its
qualified saved-value merge. The client never infers occupancy from a fixed
model-specific point list.

Review requires the exact selected input, previous terminal and free destination.
Client checks cover all review fields, two non-overlapping fixed-width payloads,
preservation flags, nested compilation seals, saved-merge evidence and the complete
review seal. Save review retains the exact response bytes. Native download checks
all five export evidence headers and hashes the actual artifact before saving.
Mismatched or late responses never become a current review or download.

At most 32 workspace drafts are retained in memory; a new draft at capacity is
refused without deleting earlier work. Drafts belong to the exact selected
controller route/interface or offline workspace. Task navigation retains local
selection while retiring reviews. Changing target, interface state, active field
work, source, basis, input or destination invalidates the relevant review.
Collapse, page hide, document visibility loss and unmount also retire pending
results; returning requires source inspection and a fresh review. The existing
allocation, mode editing, transfer and recovery flows are unchanged.

## Boundaries

The view uses existing engineering styles and compact navigation; it adds no
global destination or feature tile. It offers no Apply action. Configured free
terminal evidence is not a physical wiring survey. Integral DPT, SA/cross-host,
dedicated binary and output terminals, electrical-mode changes and allocation
remain outside this copy profile. General native compilation, resource/package
qualification, controller acceptance and physical/Bluetooth testing remain
separate work.
