# Recorded configured analog recovery lineage

`UI-NATIVE-ENCODED-ANALOG-RECOVERY-LEDGER-001` adds recorded previous-terminal
lineage to the existing configured analog movement details in Changes and
History. The operator can see the original receipt, recorded input/reference,
inverse terminal pair and historical verification time, search the recorded
parent locally and download the original child evidence.

The backend projects only the child's stored intent. Its separate closed profile
requires the exact encoded-analog namespace, typed sealed origin and independently
valid configured analog terminal metadata. Parent, current capture, object,
reference, terminal pair, configuration guard and unchanged identity must agree.
Missing or altered fields, Boolean aliases, self-parent or identical original/current
sources and mixed legacy namespaces yield unavailable metadata. Presence of any
encoded recovery field prevents fallback into an older operation family.

The browser independently checks the closed origin/report shapes, terminal and
Device bindings and the original Python-compatible origin seal, including Unicode
references. This historical digest uses the already pinned synchronous hash
implementation; it does not change field-transfer cryptography. Inconsistent
lineage cannot supply parent search or an input-tool shortcut, even if an earlier
input, terminal, binary or generic recovery record is injected alongside it.
Original evidence and recorded outcomes remain available.

Valid **Open input tools** keeps the current graph/CAF/controller workspace and
starts fresh input selection. It does not stage a recovery proposal. Parent search
is an explicit local filter; opening a record does not read its parent or source,
recompile a program, query a controller or grant transfer authority. Historical
verification does not promote an uncertain child to a verified outcome. Current
configuration, source availability and physical wiring require their own workflows.

Verification covers authored ASCII/UCS-2 inputs with present or absent linear
output endpoints; malformed and resealed origins; mixed/missing namespace fields;
actual retained verified and uncertain localhost-UDP child receipts through restarted
HTTP History; exact original downloads; no parent/source/compiler/controller access;
graph/CAF context, parent search and desktop/phone views; independent browser seal
admission; and preservation of existing ledger families. The source and installed
wheel share the qualified browser cases and exact bundled source/assets.
