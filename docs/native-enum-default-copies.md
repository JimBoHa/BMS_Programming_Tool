# Native Enum default file copies

In **Program → Native backup defaults**, select a retained backup and **Inspect
retained native backup**. Open the captured record explorer and inspect an actual
class 528 or 529 record with an Enumerated Default Value (3113). **Local Enum
default copy** accepts a decimal code from 0 through 4294967295. Review the exact
source and change, then **Save Enum file copy**. **Save Enum copy review** retains
the original response bytes. The recorded source properties remain unchanged.

This is a local original-archive edit. The code's membership in the block's Enum
set, state meanings, executable mappings, reliability and restart behavior remain
unverified. No label is guessed from the numeric code or property 931. Saved
settings are not merged; they may override an archive default in a controller.
The existing Real and Boolean effective compilers and field operations are
unchanged. This operation does not grant an Enum field-transfer path.

The native profile is `tagged-moi-enum-default-copy/1`. Eligibility requires a
fully framed native application, one root Device identity, unambiguous engineering
references, the actual class/property, and a BACnet Enumerated application tag 9
with one through four payload bytes and the native closing tag. Other tags,
classes, properties, ambiguous sources and unsupported encodings are refused.
Controller model names do not select inventories or replacement values.

The existing value width is retained when sufficient. A larger code grows the
selected payload and its record length prefix; a short record becomes extended
only when necessary. An already extended prefix stays extended. The compiler
reparses the output and verifies every unrelated record prefix and payload,
original application header/count and selected property surroundings. Captured
Enum/state metadata and unknown bytes remain intact. Plain MOI and ordinary
single-member gzip sources are supported. Gzip headers are retained and CRC/size
are regenerated; a no-op returns the entire original file unchanged.

The local service profile is `native-backup-enum-default-copy/1`. Token-admitted
`POST /api/bacnet/controller/native-application/inspection/enum-default/preview`
and `/export` bind the capture, complete snapshot seal, original File 3 hash,
record reference, exact encoding fingerprint and strict integer proposal. Export
recomputes the review and checks all original Files 3/11/12 again. No originals
are replaced. Unknown saved schemas and historical acquisition identity errors
do not prevent a structurally qualified local copy; their evidence is retained.
The operation performs no field query, connection, backup command, transfer,
credential request or transfer-journal insertion.

The browser checks exact source/station/field/class/code and operation flags,
then verifies the download's snapshot, review and artifact headers and actual
SHA-256. Editing, changing sources or tasks, hiding the page and unmounting retire
reviews and pending requests. A late response cannot restore a review or download
an artifact. Up to 128 raw source-specific proposals remain in memory, including
empty or invalid text, without evicting earlier work. **Discard local Enum draft**
releases its own proposal. This cache does not promise recovery after reloading
or closing the application.

Local qualification uses independently authored literal Enumerated tags for both
classes, all UInt32 width transitions, nonminimal widths, plain/gzip files,
short-to-extended framing, exact no-ops, opaque metadata, stale bindings,
coercions, changed originals and real token-admitted HTTP. Chromium and WebKit
exercise New application and CAF entry, phone layout, exact review/download
bytes, unfinished drafts, navigation, substituted evidence and held replies.
These checks establish this software profile, not CCT reopening, manufacturer
compiler equivalence, full-program compatibility or physical acceptance.

The broader JCI-02/JCI-03/JCI-05 work remains partial. Enum-set member evidence,
semantic validation, saved-setting compilation, field transfer and general native
logic generation require separate verified implementations. The generic backup
operation table has not yet added this new local operation.
