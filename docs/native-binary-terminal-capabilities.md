# Source-specific binary terminal support

`FMT-NATIVE-BINARY-TERMINAL-CAPABILITIES-001` adds explicit capability profile 17.
The complete profile-16 report remains a projection of the new report; defaults
and older request versions retain their behavior. The existing contextual terminal
support table adds one binary-transfer row after the original local-copy and
analog-transfer rows. The main support table and navigation stay intact.

Analysis uses the actual captured archive and saved parameters. It selects an
existing class-242 local universal input with a qualified closed configuration
and an unassigned local universal destination, then runs the real binary compiler
in memory. The witness records exact archive/effective/native/merge/output hashes,
configuration guard, unchanged state configuration, label charset and compiler
seal. Runtime counters remain historical captured values. No model inventory,
retained edit, plan, receipt, network query or controller write supplies this result.
Saved settings that would undo the proposed binding prevent qualification.

Recorded identity mismatch, unsupported source and unavailable transport remain
separate outcomes. A source that compiles still requires fresh field preflight,
current identity/source/occupancy checks, physical wiring confirmation, the full
three confirmations, one-use Apply and separate readback. This support report
never enables a transfer directly or verifies physical suitability.

The browser validates the independent closed binary witness, preserved predecessor
report, source/parameter bindings, unique operation row and status. Malformed new
or predecessor evidence withholds the contextual table and its download until
explicit reanalysis. Exact accepted endpoint bytes remain downloadable. Source,
task and controller invalidation, controller/CAF entry, and existing desktop/phone
layout rules remain. Narrow engineering tables retain their horizontal scroller.

Checks cover actual compiler output, unchanged stored files, disconnected APIs,
recorded identity/serial transport, output-only namespaces, unknown saved/settings
schemas, historical counters, charset, SA host and occupancy refusals, saved binding
conflicts, independent browser admission and exact downloads. Private retained VMA
sources are checked without committing archives or site inventories. Authored peer
transfer acceptance remains separate from physical controller/CCT acceptance.
