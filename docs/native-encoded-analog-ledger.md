# Recorded configured analog terminal movement

`UI-NATIVE-ENCODED-ANALOG-LEDGER-001` adds profile-4 analog transfer metadata to
existing Changes and History. It reads retained intent/result evidence without
opening original backups, compiling a new application or querying a controller.
The original outcome remains authoritative: recorded metadata never promotes an
uncertain attempt into verified success.

A separate closed historical profile records the selected object/reference,
previous/destination terminal, exact stored typed analog configuration and field
presence, observed ASCII/UCS-2 label encoding, fingerprints and recorded
confirmations. Paired absent output endpoints appear as Not stored; present
endpoints keep their recorded values. Original evidence downloads stay unchanged.
Current settings, values, source validity, physical wiring and transfer authority
are not established by this historical projection.

Backend admission requires explicit action/profile/compiler pairing, the sealed
terminal proof, configuration/storage validation, matching source/output hashes,
identity and confirmations, actual Slot/label payloads, consistent changes and
nonoverlapping byte ranges. Unsupported or inconsistent evidence yields unavailable
metadata and retains the original record. Explicit profile-4 records cannot fall
back to older input, analog terminal, binary or generic recovery metadata.

The browser independently admits the closed historical metadata. Summaries and
details stay inside the existing recorded-changes view. Invalid metadata withholds
tool links and earlier input/recovery views even if conflicting metadata is
injected. Valid Open input tools preserves the current graph/CAF/controller
context and starts ordinary input work; it does not populate a proposal, select a
historical target, restore confirmations or reuse an old plan. Graph/CAF, desktop/
phone layouts and all existing styles remain.

Verification covers actual authored receipts, typed/present/absent configuration,
malformed proof/identity/encoding/payloads, uncertain outcomes and restarted local
analysis with field/source/compiler access forbidden. Browser cases exercise
Changes/History, graph/CAF, exact evidence downloads, local tool navigation,
closed metadata admission and conflicting-family refusal. Earlier input, terminal,
binary and recovery records remain in regression coverage.

This feature is historical presentation only. Previous-terminal recovery for
profile 4 remains separate and will require a fresh current capture, independent
source/configuration checks and a new confirmed transfer/readback. General native
compilation, allocation/electrical changes, SA/cross-host movement, resources/
packages and physical/CCT/BTCVT acceptance remain separate. IO-02/JCI-09 remain
partial. No private inventory or scan result is embedded.
