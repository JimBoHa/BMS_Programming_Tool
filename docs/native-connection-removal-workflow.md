# Remove a native connection in Program

`UI-NATIVE-CONNECTION-REMOVAL-001` exposes the separately qualified
[local removal compiler](native-connection-removal-copies.md) in the existing
controller/application workspace.

Open a retained application through **Program → Native backup defaults**, inspect
a native diagram and choose **Native diagram operation → Remove existing
connection**. This is a focused task in the existing diagram editor; it adds no
global destination or dashboard tile.

Choose **Original archive** or **Saved effective snapshot**, then explicitly
choose **Open connections for removal**. Select an observed connection by its
source/destination references and port numbers. Saved-effective inspection merges
this snapshot's qualified retained settings first. Those settings are captured
configuration and never represented as current live measurements.

Choose **Review connection removal**, inspect the exact connection and count
change, then **Save native connection removal copy**. The review identifies the
selected connection and its optional continuation row. All remaining expanded
bytes, graph members, identity, execution order, layout and destination
configuration stay unchanged. The destination becomes unwired; its runtime
fallback or retained-value behavior remains unverified. Saving writes a local
file and sends no program to a controller.

The client independently checks the original snapshot, three retained file
hashes, diagram, connection tuple/index/count, optional continuation and
archive/effective source bindings. It verifies the nested compilation and full
review seals, then checks the downloaded artifact bytes and all five export
proof headers. **Save exact connection removal review** retains the actual
review-response bytes for that proposal.

Basis and selected-connection drafts share the existing 256-slot non-evicting
wire cache. Original and saved-effective choices stay separate, and every draft
belongs to its exact immutable application/diagram. Switching tasks, operation,
target, interface or source retires review authority without discarding those
local drafts. Page hiding, visibility changes and collapsing the editor also
retire pending review/download results. Returning to a previous context cannot
revive an earlier review or delayed download. A retained nonzero selection can
be discarded even after source inspection fails.

The workspace retains its selected controller and exact route/interface. Local
removal does not reconnect, query that controller, change the selected target,
prepare a native field intent or enable Apply. An already-owned field operation
continues to govern shared busy state. The existing teal styling, compact
navigation, readable ports, labelled controls and one primary action remain in
use.

Browser qualification uses isolated local storage and authored native applications
and protocol peers. It does not establish physical controller execution,
CCT compatibility, general native compilation, field transfer, inverse recovery,
new block/I/O allocation or Bluetooth/BTCVT acceptance. Existing broader QA
observations remain separately tracked; JCI-03/JCI-09 remain partial overall.
