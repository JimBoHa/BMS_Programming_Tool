# Combined native default and connection compilation

Program → Native backup defaults → select an actual Real field → **Combine this
default with a connection change** creates one local native file containing both
edits. The source is the selected retained native File 3/11/12 backup. The default
uses the ordinary proposed text above; the connection has its own draft. Addresses
are taken from the retained source, with its capture time and exact route shown.

Open the combined compiler, select an actual captured diagram, inspect its existing
connection and choose a qualified recorded source. Review both edits and save the
compiled native copy or the exact original review response. This workflow is
available without opening a field interface, including for serial-recorded backups.
It does not query or modify a controller. The open CAF, portable graph and live
values never substitute for the selected native source.

## Admitted local compilation

The separate `native-effective-default-wire-compiler/1` profile composes:

- One existing class 526/527 Real Default Value, property 3113, within its original
  four bytes. Decimal parsing, finite float32 range, underflow, negative zero and
  explicit rounded-value/bit review use the existing Real encoder.
- One existing native diagram connection's source index, within its original
  Unsigned width. The existing connection encoder requires a matching native
  source class/configuration, an observed outgoing pin, execution before the
  destination and no introduced cycle. Destination and pins stay unchanged.

Both existing effective compilers independently qualify the original File 3/11/12
backup and must produce identical saved-parameter merge bytes and evidence. The
retained identity must match its actual vendor 5 native root; a model name alone
does not qualify an operation. Original file, diagram, effective record, property,
tuple and Real-field hashes bind each selection and proposal.

Both edits first compile independently against that same merged image. Their
original byte ranges must be disjoint and bounded. The compiler then applies the
existing raw encoders in **both orders**, without merging saved parameters over an
edited intermediate. Reparsed output must match the two independently bounded
patches to the original merged bytes, preserve record membership and controller
identity, and produce identical complete bytes in both orders. Every other merged
expanded byte stays exact, including saved values, unknown metadata, native IDs,
block membership, connection destinations/pins, execution order and layout. If
both selected edits are no-ops, the exact merged source bytes are returned.

The review retains the original independent compiler reports and both literal
intermediate-source/last-edit reports. Their input and output hashes describe the
actual intermediate files; they are not relabeled as a single-edit result. The
outer report identifies the saved merge and combined output. Each original raw
encoder still reports its own scope, including no saved-parameter merge performed
inside that raw edit.

## Source and lifecycle guards

`/api/bacnet/controller/native-application/inspection/default-wire` exposes strict,
session-protected `source`, `selection`, `preview` and `export` POST operations.
Each operation reloads and checks the retained original manifest/files. Export
recomputes the full proposal and requires its exact sealed review. Independent
artifact, snapshot and review hash headers bind the downloaded bytes.

The browser checks source, saved merge, file hashes, actual candidate/tuple,
float32 bits, disjoint fields, independent compiler reports and both composition
orders before displaying a review. It verifies the downloaded file digest and all
three response headers before saving. Exact review export retains the original
JSON bytes, including their numeric spelling.

Combined connection drafts are independent of ordinary Real and existing
archive/effective connection drafts. Up to 256 explicit source/diagram/connection
selection slots are retained in the current workspace without eviction. Changing
tasks or reopening sources preserves unfinished proposals but retires reviews.
Source, selected field, route/interface, visibility, disclosure and proposal
changes invalidate pending results; synchronous counters also reject coalesced
default-text or connection-selector A → B → A changes. Late exports cannot save a
retired file. Discarding a combined connection draft leaves the ordinary Real
draft and its compiler available.

## Qualification and remaining work

Authored records cover plain/gzip sources, short/extended frames, all four original
Unsigned widths, float32 rounding/extremes/negative zero and independent no-ops.
Literal expected byte patches, saved Real/Boolean preservation, source corruption,
identity/type/tuple faults, strict HTTP, loopback capture and browser lifecycle
tests qualify this local composition. Source and installed-wheel runs separately
check the same implementation and built interface. No site or Bluetooth test is
part of this feature.

This adds no field-transfer grant. Existing Real-only, Boolean, Enum, wire and
other compiler/transfer profiles remain unchanged. Combined transfer requires its
own fresh selected-configuration checks, one-use intent, saved-setting handling,
readback and recovery work. New blocks, new connections, identities/allocation,
hardware changes, general native compilation, packages/resources, native execution
and CCT/firmware/physical acceptance remain separate. JCI-03 and JCI-09 remain
partial overall.
