# Encoding-preserving terminal support evidence

`FMT-NATIVE-TERMINAL-LABEL-CAPABILITIES-001` adds explicit capability profile 16.
The new analyzer first computes the complete unchanged profile-15 report, then
appends independent original-archive and saved-effective local-copy witnesses.
Each witness actually compiles a captured movable input to a captured free
universal terminal with compiler profile 3. Outputs are discarded in memory.

The witness identifies exact source/record/property hashes, input object and
reference, previous/destination terminal, free slots, compiler/output/proof hashes
and preserved recorded charset. The saved-effective witness additionally retains
the exact qualified merge evidence. Unknown charset, host/input families,
occupancy, output bindings and unavailable saved schemas remain explicit errors;
no site inventory or successful scan result is embedded in the application.

The two analyses remain independent. A source can support an original local copy
while its saved merge is unavailable. An unopened serial transport does not
prevent local compilation. Root/snapshot/vendor identity requirements still
govern the effective merge. Neither local witness grants current identity,
physical wiring/suitability, a field plan, transfer authority or binary runtime
acceptance. The analog field row retains its separate existing profile-2 rules.

## Context and compatibility

The existing Terminal copy and transfer support table requests profile 16. It
shows the current original/effective local-copy operations first and the existing
analog field operation third. Legacy local-copy rows remain in the complete
downloaded evidence and are independently validated, without duplicating them in
the three-row task table. The existing main capability table remains profile 14.

The browser validates closed witness keys, charset/preservation declarations,
source and direct-parent object binding, all existing record/property/proof hashes,
free-terminal ordering, merge identity, row uniqueness and exact status. Bad new
or predecessor evidence withholds this table and download while the independent
main analysis remains available. Exact original response bytes are downloadable.
Existing source/task invalidation, controller/CAF context and layouts remain.

The inspection capabilities endpoint requires explicit profile 16. Default
profile 12 and explicit 11–15 remain unchanged. This operation performs no
controller query, backup command, mutation intent, field receipt or application
transfer. Native compilers, writers, recovery helpers and ledgers are unchanged.

## Verification

Authored source checks compare the complete projection back to profile 15 and
recompile every reported witness independently. ASCII/UCS-2, analog/binary,
plain/gzip, unknown saved schemas, source identity mismatch, unopened serial,
separate outputs, unsupported charset, SA families and no-free-terminal cases
remain separate. Strict HTTP/session/source guards run with field/mutation paths
replaced by failing sentinels. Browser checks retain older reports and cover
malformed witnesses, exact downloads, draft/context retention, phone layout and
late analysis retirement.

Supplemental read-only checks of retained native archives produce eight local
original/effective VMA witnesses; the PCG SA/IOM source remains unsupported. No
private controller bytes or program names are committed. Initial browser checks
caught backend append order leaking into the task table; the interface now sorts
the visible subset by its explicit task order before rendering. That failure is
retained in local reports and excluded from final-build qualification.

Binary field configuration/runtime, SA/IOM/cross-host reassignment, resources/
packages and physical/CCT/BTCVT acceptance remain separate work.
